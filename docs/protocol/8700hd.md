# 8700HD interoperability notes

Reference: original OPTIMOD-FM 8700HD firmware 1.0.2.161 (document version 8700.51) running in the Optimod emulator, and the original Windows PC Remote 1.0.2.161. Captured on 20 and 21 October 2026. The emulator runs the unmodified firmware; it does not implement this protocol itself.

## Session

PC Remote uses TCP 6201 and the same login and five-byte framing as the 5700i ([5700i notes](5700i.md)). The login answers `8700HD V 1.0.2.161`. The status (terminal) port answers with the banner `Orban Optimod 8700HD V 1.0.2.161`. The app does not need the terminal for a connection, the settings, the presets, a write or a user preset Recall. Only a factory preset Recall uses it (see below).

Opcodes that differ from the 5700i:

| Purpose | 5700i | 8700HD |
|---|---|---|
| Response boundary (request / answer) | 250 / 251 | 249 (F9h) / 250 (FAh) |
| On-air file request (answer 229, `OnAir.orb86onair`) | 239 | 238 (EEh) |
| Setup file request | 240 | 239 (EFh), answered by 232 (E8h) `Setup.orb86setup` |
| User preset files | none | 242 (F2h), answered by one 231 (E7h) per file, then FAh |

Meter poll 219 (DBh), meters on/off 222/223 (DEh/DFh), parameter write 227 (E3h, `NAME;D-index;Type:value;scope;`) and disconnect 218 are the same. The unit sends its clock (246, F6h) every second. Meter records (228, E4h) carry bank 1 and 104 values. Values 73 to 90 are always 55h, as documented for the emulator.

Request 226 (E2h) is answered by FAh only. 240 (F0h) and 241 (F1h) are answered by FAh only. 243 (F3h) returns `Password.orb86pas`; the app never requests it.

## Files

Every file is AES-CBC with ciphertext stealing, keyed with the access code, the same as on the 5700i. The unit's own files end lines with CR LF. The `F2h` answer:

- includes `SETUP.ORB86SETUP` and files of other models that were copied onto the unit (seen: a 6300 document named `.orb86user`, an 8400 document). The app lists only `.orb86user` files whose document is an 8700 document.
- sends the firmware's `modif <preset>` working copy twice. The app lists it once, as unsaved.
- names a preset by its file name, while the document inside has its own `Preset Name` (for example `3FM_STREAM_8700_HD_FROM_6300_V08.ORB86USER` holds `3FM STREAM 8700 HD V01`). On air, the unit reports the document's name, so the app uses that.

The setup file repeats `C:<PILOT SYNC>String:<REF IN>;D:0;` on two lines. The parser accepts a field repeated with the same value and index, and still rejects a conflicting repeat.

## Changes and readback

After a write, the firmware saves `OnAir.orb86onair` 4 to 7 s later (measured on the virtual 8700 at real time). A read before that returns the previous state. Writes are therefore confirmed by reading the file again every second, for at most 15 s, until the field has the written value. Setup writes behave the same way. When the value equals the saved preset again, the firmware drops `modif` from the name.

## Recall

Recall in the original PC Remote is a file dialog on its local document folder. It sends the chosen preset as an unnamed on-air file: 229 with `0\n0\n\n<size>\n` and the encrypted document with LF line ends. It follows the file with FAh, which the unit answers with FAh, and then sends F9h.

- **User preset.** The client sends the document it downloaded with `F2h`. The app does the same. The firmware also saves that document over the user preset's file, now with LF line ends. Its fields stay identical.
- **Factory preset.** The client converts the factory file from its installer (version 8600.40, 193 fields) into a full 8700.51 document (231 fields) with its own tables. The app does not have those tables or the factory files. It therefore sends the firmware's own `RP NAME[code]`, which the unit answers with `ON AIR: NAME`. For ROCK-MEDIUM, the document the firmware loaded and the one the client uploaded agreed on 230 of 231 fields. Only `HD MULTIBAND CLIP` differed: the firmware set -1.00 dB, the client 0 dB.

After a terminal `RP`, the unit pushes the new on-air file (unnamed 229) on the PC Remote session, followed by FAh that answers no request. Counting that FAh as an answer ended the next read before its file arrived. The app now counts a pushed file's FAh as one more boundary answer.

The factory preset names come from the PC Remote 1.0.2.161 installer (64 names). The terminal `LP` command lists every preset, user presets included, as `factory`, in upper case.
