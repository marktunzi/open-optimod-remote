# 8700i interoperability notes

Reference: original OPTIMOD-FM 8700i firmware 1.5.1.11 (document version 8700.52) running in the Optimod emulator, and a captured session of the original PC Remote 1.5.1.11 against it (21 October 2026).

The login answers `8700i V 1.5.1.11`; the status port answers `Orban Optimod 8700i V 1.5.1.11`; the factory access code is ADMIN. The requests are those of the 5500i ([5500i notes](5500i.md)): FAh/FBh boundary, EFh → `OnAir.orb87onair`, F0h → `Setup.orb87setup` (E9h), F3h → preset files (E7h), F4h → password file. Meter records carry bank 1 and 112 values.

The original client sends the passcode text (CCh), meters off (DFh), E2h+F3h, F0h, then EFh, F1h, F2h and F4h. The firmware answers the file requests without the passcode message or meters off; the first probes got no answer only because the scratch unit was still starting up.

Like the 5700i, the 8700i cuts a frame that does not fit its send buffer while session meters are on. The 8.4 KB document it pushes after a terminal `RP` broke the session ("Invalid frame header") until the 5700i's cut-frame handling was enabled for it. A pushed document carries LF line ends.

Factory Recall uses the terminal's `RP`; a user preset is sent back as an unnamed on-air file followed by FBh.
