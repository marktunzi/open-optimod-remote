# 5500 interoperability notes

Reference: original OPTIMOD 5500 firmware 1.2.8.24 (`bin/_optimod.exe` in the installer's `update.zip`) and the original Windows PC Remote `5500PC.exe` 1.2.8.24, read statically on 28 October 2026. No 5500, physical or virtual, was available: nothing below has been seen on a running unit.

## Generation

The 5500 speaks the 8700HD PC Remote generation ([8700HD notes](8700hd.md)), not the 5500i's. Its firmware answers PC Remote requests in one switch (0x344013). That switch is the 5500i firmware's (0x34a42c) with every opcode one lower and without the network file. Every 5500i opcode in that switch is one captured from the 5500i firmware ([5500i notes](5500i.md)), which is why the table below is trusted.

| Purpose | Request | Answer |
|---|---|---|
| Response boundary | 249 (F9h) | 250 (FAh) |
| On-air file | 238 (EEh) | 229 (E5h) `OnAir.orb55onair` |
| Setup file | 239 (EFh) | 232 (E8h) `Setup.orb55setup` |
| Automation file | 241 (F1h) | 234 (EAh) `Automation.orb55autom` |
| Preset files | 242 (F2h) | one 231 (E7h) per file (`.orb55user`, `.orb55setup`) |
| Password file | 243 (F3h) | 230 (E6h) `Password.orb55pas` |
| Delete a file | 236 (ECh) `NAME.ext\n` | none |
| Diagnostics | 204 (CCh) + access code | 205 (CDh) |

There is no network file: neither the firmware nor the client names one. The client's sync also sends F0h, which the firmware does not handle; the app does not send it.

The login answer may or may not end with a session line (the client's code does not show which), so the app accepts both.

## Documents

The firmware writes `OptimodVersion=<5500.50>` documents, the only version string in `_optimod.exe`. The installer's factory files are `8300.10` (two are `5500.10`). The app accepts the 5500's `5500.` and `8300.` families.

## Client functions

`5500PC.exe` has the 5500i client's menus without Open Setup and Save Setup As. Each function below is the 5500i client's code with the opcode one lower:

| Function | 5500 client | 5500i client |
|---|---|---|
| Save, Save As | 229 upload of the on-air document under the new name | same |
| Delete Preset | ECh (0x465f00) | EDh |
| Backup to PC | EFh, F2h, F1h, F9h (0x458f70) | F0h, F3h, F2h, F1h, FAh |
| Restore from PC | `Automation.orb55autom` as EAh, `Password.orb55pas` as E6h, anything else as 231 (0x443130) | EBh, E6h, `Network.orb55net` as EAh, else 231 |
| Automation | F1h; upload EAh with FILETIME (0x4096af) | F2h; EBh |
| Security | F3h; upload E6h | F4h; E6h |
| Access levels | the 5500i's bounds; Delete needs level 1 or lower | same |
| System Setup | 8 tabs: Input, Output, Test, Utility, Network, Stereo Encoder, Remote Interface / Silence, Diversity Delay (property sheet 0x447220) | the same 8, then 2 more |

The security level names, the automation functions and the file format (5500.50) are the 5500i client's.
