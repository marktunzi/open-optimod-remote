# 5500i interoperability notes

Reference: original OPTIMOD 5500i firmware 3.1.0.2 (document version 5500.50) running in the Optimod emulator, and the original Windows PC Remote 3.1.0.2. Captured on 21 October 2026.

## Session

Login, framing and access-code encoding as on the 5700i ([5700i notes](5700i.md)). The login answers `5500i V 3.1.0.2`; the status (terminal) port answers `Orban Optimod 5500i V 3.1.0.2`. The opcodes are the 5700i generation:

| Purpose | Request | Answer |
|---|---|---|
| Response boundary | 250 (FAh) | 251 (FBh) |
| Poll | 219 (DBh) | 220 (DCh), or meter records while meters are on (222) |
| On-air file | 239 (EFh) | 229 (E5h) `OnAir.orb55onair` |
| Setup file | 240 (F0h) | 233 (E9h) `Setup.orbsetup` |
| Network file | 241 (F1h) | 234 (EAh) `Network.orb55net` |
| Preset files | 243 (F3h) | one 231 (E7h) per file |
| Password file | 244 (F4h) | 230 (E6h); never requested by the app |

Requests 226 (E2h) and 242 (F2h) are answered by FBh only. Meter records carry bank 1 and 86 values. As on the 8700HD, the unit also sends the right-channel AGC and gain-reduction values (10/11, 17/18) that the original client's single bars do not use.

The firmware's own documents (on-air, setup, network, user presets, terminal AP) are version `5500.50`. The factory files in the PC Remote 3.1.0.2 installer are the older `8300.10`.

## Preset files

The `F3h` answer holds the unit's `.orb55user` files, the firmware's `modif <preset>.orb55f50` working copies of factory presets, and its setup files. The app lists only `.orb55user` files. The factory list is the 27 base presets of the installer, the same 27 the front panel's Recall list shows.

## Recall and Save Preset As

Both are uploads of an unnamed on-air file (229), followed by FBh, which the unit answers with FBh:

- **Recall of a user preset** sends that preset's document.
- **Recall of a factory preset**: the client converts the installer's 8300.10 file (89 fields) into a 5500.50 document (113 fields). The firmware's `RP` produced the same 113 fields for JAZZ (0 differences), so the app uses `RP` for factory presets, as on the 8700HD.
- **Save Preset As** sends the on-air document with `Preset Name` and `Preset File Name` changed to the new name. The firmware stores `<name>.orb55user` and puts it on air.

A pushed on-air file is followed by FBh, as on the 8700HD (where the marker is FAh).
