# Open Optimod Remote 0.2.0

Open Optimod Remote now covers its three initial models, the OPTIMOD 5500, 5700i and 8700HD, each with parameter writes, preset recall, live meters and every system setting. More models will follow.

## OPTIMOD 5700i

- Still the only model verified on a real processor (firmware 3.0.1.20). All controls, recall, preset files and live meters work as in 0.1.0.
- Its hardware-verified parameters, processing pages and meters are unchanged, and changes to them keep the fast path verified in 0.1.0.
- New: 199 more settings (364 scope entries) from the official 5700i PC Remote, including the two-band structure, the MX structure for units with Orban's paid MX upgrade (7 extra pages), test tones and the clock. A page appears only when the processor reports its fields, so a 5700i without the MX upgrade shows no MX pages. These are statically derived, so every change to them is read back from the processor.
- The native System Settings window stays 5700i-specific.

## Presets and backup (all three models)

- The Presets workspace is now also used by the macOS app. It saves the on-air preset as a file with the model's own extension (`.orb55user`, `.orb57user`, `.orb86user`) and applies a preset file with every value verified.
- **Backup:** one JSON file with the system settings, the on-air preset and the names of all presets. **Restore** shows first which system settings it will change and which it leaves alone, never changes network settings or the clock, and reads every change back. User presets that are not on air are not in the backup: their contents can only be read by recalling them.
- **OPTIMOD 5500 only:** save the on-air processing as a new user preset, rename the on-air user preset and delete a user preset that is not on air, using the `SP` and `DP` commands its firmware documents. Every change is confirmed by reading the preset list back. The 5700i and 8700HD firmware have no such command, so these actions are not offered there.

## OPTIMOD 5500 and OPTIMOD-FM 8700HD

- **OPTIMOD 5500** (firmware 1.2.8.24) and the original **OPTIMOD-FM 8700HD** (firmware 1.0.2.161): change settings, recall presets, live meters and each model's own processing pages and meter layout.
- The 8700HD is its own model, with its own skin, network discovery and connection choice. It is not the 8700i.
- `scripts/extract_pc_remote.py` derives a complete model profile from an official Orban PC Remote installer. [Adding a model](../adding-a-model.md) describes the next one.

## Important: not yet tested on hardware

The 5500 and 8700HD profiles are derived from Orban's official PC Remote software and firmware and cross-checked against the factory presets. They have **not been verified on a real processor**. The app shows this while connected, and:

- writes a setting only when the processor's current value matches the profile;
- reads the complete settings back after every change and shows the processor's real value if it differs;
- never retries a failed write;
- keeps fields that contradict the factory presets read-only;
- keeps other firmware versions of these models read-only.

Test on a processor that is not on air first. If you own a 5500 or 8700HD, please report the result of one reversible change (for example display contrast) in an issue. That is what turns these profiles into verified ones.

## Known limitations

- The native Settings window supports only the 5700i. Other models use the Setup workspace, which places every system field in the same ten categories; System Settings… and Command-, open it for them.
- Saving, renaming and deleting presets on the processor: only on the 5500.
- Not available on any model: passcode management (the access level is shown as a setting), the automation schedule, and maintenance (reboot, factory reset, firmware update).
- Fields that contradict the factory presets are read-only: 9 on the 5500 and 9 on the 8700HD.

## How reliable is a derived profile?

The same method applied to the 5700i PC Remote reproduces 363 of the 366 hardware-verified 5700i mappings exactly, and none wrong. The remaining 3 are left read-only or given a narrower safe range.

## Fixes

- Preset recall and applying a preset file no longer assume a 5700i.
- The macOS preset file panels named the 5700i for every model and showed `(url.lastPathComponent)` instead of the file name.
- Command-, opened the 5700i Settings window for every model.

## Requirements

Apple Silicon Mac, macOS 13 or later. The release build is signed with a Developer ID and notarized by Apple (`scripts/release-macos.sh`).
