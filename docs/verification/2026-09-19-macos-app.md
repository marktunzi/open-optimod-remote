# One-click macOS app verification, 19 September 2026

> **Evidence status:** Point-in-time packaging record. The build/install workflow remains current, while current features and limitations are maintained in [HANDOFF](../HANDOFF.md).

Target: Apple Silicon macOS, installed at `/Applications/Open Optimod Remote.app`. No processor connection or device mutation was used for this packaging verification.

## Verified behavior

- Finder/macOS `open` launches a normal Dock application with a resizable native window.
- The app starts `Contents/Resources/backend/orban-web` as its child and accepts readiness only when `/api/health` returns the expected `open-optimod-remote/` identity.
- The bundled service serves `Contents/Resources/ui`; the root document and hashed JavaScript and CSS assets load successfully in the embedded WebKit view.
- The complete disconnected interface renders in the window, including saved connection choices, fixed-width grouped meter wells, FM/HD views, Processing, Presets, Outputs and Setup navigation.
- The installed bundle includes the consolidated global bar and the task-oriented ten-category Setup interface.
- The embedded launch sets `OPEN_OPTIMOD_NO_BROWSER=1`. The service does not open the system browser.
- Quit first requests `/api/disconnect`, then stops only the child service started by the app. The helper process, loopback health endpoint and matching PID file are gone after Quit.
- Both the source bundle in `dist` and the installed bundle pass strict deep ad-hoc signature verification and property-list validation. The launcher and backend are native arm64 Mach-O executables on the tested Mac.

## Automated checks

The release candidate passed the complete Rust workspace tests, Clippy with warnings denied, Rust formatting, all ten TypeScript tests, the production Vite build, the standalone Swift launcher contract test, shell syntax checks and a fresh bundle build. The meter suite includes an explicit invariant that every channel retains the same fixed width in FM, HD and Both views. Setup coverage reads the committed 178-field inventory, and coupling coverage rejects a confirmation after its preset or session changes. The installed UI was also checked for overflow and overlap at 1440×900 and 1180×760; details are in `2026-09-19-ui-audit.md`.

## Distribution boundary

The installed development build is ready for one-click use on this Mac. It is ad-hoc signed and is not notarized. A public binary release still requires an Apple Developer ID, notarization, release artifacts for supported architectures and a clean-machine installation test. This packaging milestone does not change the feature-parity limits documented in `docs/compatibility.md`.
