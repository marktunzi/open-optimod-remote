# Development verification, 15 September 2026

> **Evidence status:** Point-in-time record from the initial milestone. Counts, UI scope and open gates were superseded by later reports; use [HANDOFF](../HANDOFF.md) for current status.

Target: Apple Silicon macOS, OPTIMOD 5700i firmware 3.0.1.20. Device credentials, network address and station/preset contents are deliberately excluded.

## Completed evidence

- Rust protocol tests cover every legal frame length, fragmentation/coalescing, checksum/complement corruption, truncated streams, access-code framing, rejected authentication, typed changes, delimiter injection, file boundaries, document validation and independent AES-CBC-CTS vectors.
- 355 static parameter value mappings matched the reference device's current typed values and indices without mismatches. This is one current-value cross-check per field, not an exhaustive hardware sweep.
- Native diagnostic: 222 processing fields, 178 setup fields, 286 meter frames per bank over 30.1 seconds. Both banks changed 256 times; maximum poll duration in that run was 219 ms.
- Native contrast check: current contrast 3 → 2 → 3, readback after both changes, all 400 fields restored. An earlier out-of-range value was ignored; the supported range is 0–3.
- Browser hardware test: login, all 400 fields, 20 live meter events with 19 distinct states, local FM/HD switching with zero write requests, contrast changed by keyboard and restored with two requests. No browser exceptions. All fields matched the baseline after restoration.
- Mocked browser regression: keyboard focus was lost when a pending write disabled the input. The reproduced failing test now passes after keeping the input focusable while preventing duplicate edits. Mocked requests never reached the device.
- HTTP tests: foreign Origin, missing Origin on mutations and mismatched Host are rejected; a write with no active device cannot create optimistic state.
- macOS bundle validates as a plist and contains a native arm64 main executable plus local-network usage description. The packaged process connected to the processor and passed the same browser hardware test: 20 live events with 20 distinct states, no view-switch writes, contrast restored and all 400 fields unchanged. The earlier shell launcher failed local-network access; the native main executable replaced it.
- Eight FM/HD equalizer frequency mappings and three time-setting mappings were added. Frequency endpoints, piecewise bass steps and units have regression coverage. The current values of all 355 definitions matched the device; no audio setting was changed to test these new mappings. Numeric units were recovered for 178 definitions.

## Boundaries

The hardware tests changed only display contrast. No audio processing, routing, presets, automation, RDS, security, licenses or firmware were changed. Processing controls have value validation and readback but still need representative hardware checks and exact Windows comparison.

The UI currently has 15 reference-derived processing layouts and 195 mapped controls. Some are unavailable in the active preset or await value mappings. Missing system workflows are read-only. Meter bars use real raw values; calibration and complete current/peak behavior remain unfinished. This build is not suitable to call a complete Windows replacement.
