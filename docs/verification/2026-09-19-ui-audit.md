# Interface audit, 19 September 2026

> **Evidence status:** Point-in-time interface record. Later artwork, native-window and metering changes supersede its UI counts; use [HANDOFF](../HANDOFF.md) and the later verification files for current behavior.

Target: the installed native macOS app and its embedded local interface. The live processor session was used only to populate the interface. The audit did not submit parameter, routing, preset or coupling changes.

## Result

- Connection state, on-air preset and confirmed FM/HD coupling now share one global top bar. Coupling is the only setting in that bar.
- System Setup exposes ten task-oriented categories with ordered subsections, friendly English labels, current values and direct actions. Device status is visibly read-only and physical source fields open Outputs.
- Empty or unavailable text values render as `Not Configured` instead of a raw implementation value.
- Search covers the friendly label, original device field name, subsection and category and reports an explicit result count or empty state.
- Saved-connection deletion requires a confirmation step. Form fields have labels, names and autocomplete behavior, status messages use live regions and keyboard focus remains visible.
- Meter lanes retain a fixed channel width in FM, HD and Both views. The canvas scrolls horizontally when the window cannot show every group at that width.

## Geometry regression

A Playwright audit ran at 1440×900 and 1180×760. It checked the global native layout, all ten Setup categories, all nine FM processing pages, all seven HD processing pages and the minimum-size Setup layout. Hidden assistive text and native range-input internals were excluded from geometry comparisons.

All checked views reported:

- zero text or interactive-element overlaps;
- zero unintended horizontal content overflow;
- no browser exceptions during navigation.

The production TypeScript build and all ten UI tests passed after the audit. The UI tests include fixed-width meter lanes, meter motion/staleness, FM/HD channel separation, the complete 178-field Setup inventory and stale coupling-confirmation rejection after a preset or session change.

## Remaining boundary

This audit proves layout behavior for the current field inventory and tested window sizes. It does not prove complete visual or workflow parity with every page and dialog in the matching Windows PC Remote release. That comparison remains tracked in `docs/compatibility.md`.
